# Рабочая папка Евы

Проверяй исходники и существующие инструкции проекта перед правками. Используй отдельную ветку или рабочую копию, когда это нужно. Проверяй изменения и сообщай о результатах. Храни ключи, личные данные, резервные копии и историю чатов вне репозитория.

Доступные операции перечислены в `node /root/codex-mobile/eva-ops.js list`. Там собраны команды телефона, сопряжённого ADB, заметок, задач, SSH-серверов, GitHub и сборки APK. Для адресов и служб пользуйся именами из `server list` и локальным профилем операций. Действие с личными данными, перезапуск службы и публикацию запускай по поручению пользователя.
