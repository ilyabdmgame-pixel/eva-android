# Материалы комнаты

Четыре оригинальных листа PNG имеют размер 1254 × 1254 пикселя. На каждом листе четыре разных образца по 627 × 627. При упаковке каждый образец уменьшается до 512 × 512 отдельно. Готовый атлас 2048 × 2048 лежит в `app/src/main/assets/home/art/room-indie-atlas.webp`.

| Лист | Слева сверху | Справа сверху | Слева снизу | Справа снизу |
|---|---|---|---|---|
| timber | Медовые половицы | Тёмный орех | Крашеное бирюзовое дерево | Светлый дуб |
| walls | Шалфейная штукатурка | Обои индиго с листьями | Кремовая плитка | Старый кирпич |
| fabric | Ягодное стёганое покрывало | Узорчатый ковёр | Светлый лён | Сливовый вельвет |
| hardware | Графитовый металл | Кремовая эмаль | Бирюзовая керамика | Листва |

Листы созданы встроенным ImageGen для этой сцены. Художественное задание для каждого листа — *cozy late-1990s indie RPG, original hand-painted diffuse albedo, four equal square seamless material samples filling a 2 × 2 grid edge to edge; flat, orthographic, even ambient light, no labels or margins*. Для отдельных плиток заданы материалы из таблицы, характерный рисунок дерева или ткани и общая палитра из медового дуба, шалфея, бирюзы, сливы и терракоты.

Скрипт читает квадраты каждого исходника по строкам и кладёт их в одну строку атласа. Чтобы пересобрать готовую текстуру, установи Pillow и запусти `python3 tools/bake_room_materials.py`.
