# Лицензии

MIT в корне относится к исходному коду Евы. Графические материалы из проекта поставляются отдельно от лицензии кода до подтверждения условий их распространения.

При сборке используются [Codex](https://github.com/openai/codex), [Vosk](https://github.com/alphacep/vosk-api) и [JNA](https://github.com/java-native-access/jna). В Linux-среду также входят PRoot, Node.js, Python и библиотеки дистрибутива. Эти компоненты и распознающая модель распространяются по собственным лицензиям. Сборка для разработки использует локальные файлы зависимостей. Для распространения готового APK проверь происхождение версий, уведомления о лицензиях, условия перераспространения и требования к предоставлению исходников для вложенных компонентов.

В проверенном тестовом архиве Linux отсутствуют каталоги лицензионных уведомлений дистрибутива. В нём нужно зафиксировать происхождение версий и комплект уведомлений. Импорт из прежнего APK адаптирует путь загрузчика PRoot в бинарнике. Для публичной сборки нужны соответствующие исходники конкретной версии с патчами и сведения о сборке. [Лицензия PRoot](https://github.com/proot-me/proot/blob/master/COPYING).

Архив распознавания содержит каталог `vosk-model-small-ru-0.22`. Издатель указывает Apache 2.0 для этой модели. Перед выпуском нужно сверить файлы модели с исходной поставкой и добавить её уведомления. [Каталог моделей Vosk](https://alphacephei.com/vosk/models).
