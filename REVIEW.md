# Ревью перед публикацией

| Что нашла | Что изменила |
|---|---|
| Голосовые приветствия и благодарности могли уйти во внешний API без истории чата. | В режиме Codex текст и диктовка используют один маршрут. Внешний провайдер выбирается пользователем. |
| `thread/resume` сам по себе сохранял прежние инструкции старого чата. | Характер передаётся в инструкции Codex на каждом ходу. Проверка возобновляет настоящий старый rollout через app-server и сверяет входящий запрос к API. |
| APK собирался из предыдущего APK, наложений и модифицированного DEX. | Один Android-модуль компилирует чат, питомца и «Дом» из исходников. Среда и приложение распаковываются по версиям собственных архивов. |
| «Дом» и чат связывались через экспортированный сервис и фиксированный пакет. | Сервис находится внутри одного приложения. Чат и «Дом» открывают друг друга явными Android-интентами. |
| В исходниках были личные обращения, рабочие привязки и фиксированные координаты. | Убраны персональные данные, рабочий чат стал общим, координаты опциональны, время берётся с устройства. Репозиторий собран заново из выбранных файлов. |
| Пробный APK использовал общий режим cleartext и отладочную конфигурацию. | HTTP разрешён для внутреннего адреса 127.0.0.1. Отладка в release-сборке выключена. Для тестового APK используется отдельная подпись. |

Остаются проверки на телефоне с реальной учётной записью, разрешениями, голосом, уведомлениями и домашним экраном. Сборка Linux-среды пока требует предоставленных отдельно компонентов. Для публикации APK нужно подтвердить условия распространения графики и вложенных зависимостей.
