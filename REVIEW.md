# Ревью перед публикацией

| Что нашла | Что изменила |
|---|---|
| Голосовые приветствия и благодарности могли уйти во внешний API без истории чата. | В режиме Codex текст и диктовка используют один маршрут. Внешний провайдер выбирается пользователем. |
| `thread/resume` сам по себе сохранял прежние инструкции старого чата. | Характер передаётся в инструкции Codex на каждом ходу. Проверка возобновляет настоящий старый rollout через app-server и сверяет входящий запрос к API. |
| APK собирался из предыдущего APK, наложений и модифицированного DEX. | Один Android-модуль компилирует чат, питомца и «Дом» из исходников. Среда и приложение распаковываются по версиям собственных архивов. |
| «Дом» и чат связывались через экспортированный сервис и фиксированный пакет. | Сервис находится внутри одного приложения. Чат и «Дом» открывают друг друга явными Android-интентами. |
| В исходниках были личные обращения, рабочие привязки и фиксированные координаты. | Убраны персональные данные, рабочий чат стал общим, координаты опциональны, время берётся с устройства. Репозиторий собран заново из выбранных файлов. |
| Пробный APK использовал общий режим cleartext и отладочную конфигурацию. | HTTP разрешён для внутреннего адреса 127.0.0.1. Отладка в release-сборке выключена. Для тестового APK используется отдельная подпись. |

## Версия 0.105

| Наблюдение | Исправление и проверка |
|---|---|
| Проекции мебели и отдельные изображения сидящей Евы расходились при смене ракурса. | Комната, мебель, скелет, контакты с полом и предметы используют одну трёхмерную систему координат. Переходы на кресло и кровать проверяются по фазам и после поворотов мебели. |
| Картинка игры на мониторе повторялась независимо от происходящего в чате. | Платформер считает физику фиксированными шагами, события прыжков, столкновений, проигрыша и завершения уровня попадают в симуляцию. Зрители и Ева реагируют на события текущей партии. |
| Если несколько окон слушали события чата, они получали одну и ту же команду Android. | Сервер выбирает одного нативного получателя. При разрыве сообщает о неподтверждённом результате. Тест держит одновременно три подключения и проверяет отключение активного. |
| Невидимые портреты и полноразмерные растровые кадры занимали память и место в установке. | Чат загружает позы по потребности. Исходные PNG остаются в репозитории, в APK попадают WebP. При обновлении снимаются только те старые штатные файлы, для которых совпадает хэш и уже установлена замена. Тест миграции сохраняет изменённые изображения, ссылки и личные файлы. |
| Рендер сцены мог оставить рабочий стол без управления при ошибке драйвера. | В запасном режиме доступны приложения, чат, часы, меню и диспетчер. Для восстановления графики есть повторная попытка. |
| Проверки Java для питомца запускались отдельно, а аудит APK не ловил пропуск файла приложения. | Общий прогон компилирует Java-тесты. Аудит сверяет полный перечень файлов и их содержимое, в том числе новые графические ресурсы. |

Проверки интерфейса используют отдельные пользовательские профили, синтетические показатели устройства и тестовые диалоги. Для частоты кадров на конкретном Android-устройстве и поведения системного жеста MagicOS нужен замер на самом устройстве.

## Питомец и «Дом» в 0.65

| Что нашла | Что изменила |
|---|---|
| Окно питомца могло перехватывать касания над экранной клавиатурой. | При видимой клавиатуре окно пропускает касания, а питомец выбирает место вне поля ввода. |
| Посадка и подъём использовали один темп и могли сбрасывать положение при прерывании. | Добавлены отдельные фазы, плавная привязка к опоре и подъём из текущей позы в «Доме». |
| В разделе «Вне папок» основное касание открывало список папок. | Основное касание запускает приложение. Отдельное меню управляет папкой и значком рабочего стола. |
| Город часто рисовал неподвижные сцены и опрашивал чат на скрытом экране. | Движение запрашивает кадры сразу, окружение — реже. При уходе в фон кадры и опрос чата останавливаются, расписание мира обновляется вне потока интерфейса. |

## Проверки 0.69–0.72

- На HONOR X9d проверены запуск и обновление на месте с сохранением хранилища, использование «Дома Евы», отдельные переключатели темы и питомца, запуск приложений и отдельные ярлыки.
- На устройстве проверены контакт стула с верхней границей клавиатуры, проход касаний, мини-чат выше клавиатуры, повторное открытие с черновиком и доступность «Уточнить сейчас» после набора текста. Карточки проверены с текстовыми и структурированными примерами.
- Запуск голосового окна проверен системным интентом с имитацией распознавания. Отдельно остаются проверка на физической Bluetooth-гарнитуре, длительная работа в фоне и визуальный проход по всем анимациям на нескольких устройствах. Автоматические проверки движений покрывают в том числе шаг, посадку и подъём, лестницу, канат и прерывания.
- В 0.72 обновлены модели по умолчанию, выбранные вручную модели сохраняются. В запросы внешним моделям передаётся исходный текст реплик без подписей кнопок опроса. Локальные тесты проверяют формат запросов Codex, Gemini, DeepSeek, Claude и OpenRouter, передачу характера и истории, выбор модели, ошибки и отмену. Доступ к конкретным моделям и ответы рабочих аккаунтов нужно проверять с ключами провайдеров.
- На HONOR проверены читаемость нового приветствия, основные значки меню, выбор внешней модели и её настройки без API-ключа, запуск сцены «Дома» и отказ в доступе к микрофону. После отказа поле ввода остаётся доступным, приложение показывает инструкцию по включению разрешения.
- В 0.72 отладка WebView включается только у приложения с флагом отладки Android. У тестовой установки сокета удалённой отладки WebView нет.

Тестовая сборка использует локальный комплект Linux-зависимостей. Для публичного APK остаются происхождение графики, уведомления о лицензиях вложенных компонентов и соответствующие исходники изменённых бинарников. [Состав и лицензии](THIRD_PARTY.md).
