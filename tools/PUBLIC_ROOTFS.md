# Публичная среда Евы для ARM64

`prepare_public_rootfs.py` собирает `rootfs.pack` из официального дистрибутива Node.js 22.22.1, npm-пакетов `@openai/codex` 0.167.1 с ARM64-компонентом и 133 пакетов Debian 13.8. Для сборки нужны Python 3.11+ со стандартной библиотекой, доступ к HTTPS, около 3 ГБ свободного места и файловая система Linux с символическими ссылками. Хостом может быть x86-64 или ARM64.

```sh
python3 tools/prepare_public_rootfs.py --output local-runtime/rootfs.pack --cache /tmp/eva-runtime-downloads
```

`public-rootfs.lock.json` фиксирует SHA-256 всех загружаемых файлов. Для Debian указаны зеркало архива и датированный снимок от 22 ноября 2026 года. Архивный индекс `trixie/InRelease` относится к выпуску Debian от 21 ноября. Внутри образа список пакетов, версий, адресов и SHA-256 лежит в `/usr/share/eva-userspace/manifest.tsv`. Генератор задаёт порядок записей, их владельца, права и время. Он не запускает скрипты установки пакетов.

В образ входят Python 3.13, GNU Bash и базовые утилиты, Git, клиент OpenSSH, ADB 34 с беспроводным сопряжением, npm, Codex и поставляемый с ним `rg`. Корневые сертификаты берутся из пакета `ca-certificates`. При запуске Android передаёт DNS своей активной сети. Каталоги `/root` и `/home` в образе пусты. Приложение распаковывает прикладную часть отдельным архивом.

## Проверка в изоляции

На ARM64 Linux процесс с правом `chroot` может выполнить проверку готового архива. Она открывает отдельный временный корень, вызывает инструменты с чистой средой и выполняет `initialize` локального Codex app-server через стандартные потоки. Затем проверка разворачивает тот же прикладной слой, который попадает в APK, и первый раз запускает `/usr/bin/node /root/codex-mobile/server.js` в чистом домашнем каталоге. Она ожидает `EVA_READY`, получает HTML, скрипт и портрет по HTTP и проверяет готовность Codex без учетной записи. Для ADB читаются версия и справка.

```sh
python3 tools/prepare_public_rootfs.py --output local-runtime/rootfs.pack --cache /tmp/eva-runtime-downloads --smoke
```

## Соответствующие исходники и лицензии

Для выгрузки архива исходников из того же набора добавь `--sources`. В каталоге результата появятся подписанные Debian `.dsc`, оригинальные исходники, патчи Debian, исходные архивы Node.js, Codex, ripgrep и компоненты голосовой подсистемы, перечисленные в пакете Codex. В корне каталога сохраняется копия lock-файла. Контрольные суммы Debian взяты из опубликованных `Packages` и `Sources`, контрольные суммы голосовых компонентов — из `codex-resources/voice/sources.json`. Сборочный скрипт проверяет SHA-256 каждого загруженного файла и повторно проверяет файлы в кэше.

```sh
python3 tools/prepare_public_rootfs.py --sources-only --sources /tmp/eva-public-sources
```

Внутри `rootfs.pack` Debian сохраняет `copyright` каждого пакета и каталог стандартных лицензий. Лицензия Node.js лежит в `/usr/LICENSE`, уведомления Codex, ripgrep и bubblewrap — в `/usr/share/doc/openai-codex`. Отдельные уведомления и источники голосового компонента находятся внутри поставляемого платформенного npm-пакета Codex.
